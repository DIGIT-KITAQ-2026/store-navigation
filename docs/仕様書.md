# store-navigation 仕様書

## 概要

スーパーやコンビニで「商品がどこにあるか分からず店員に聞く」ことによる、消費者・店員双方の負担を解消するアプリ。スマホで商品を検索し、店内ナビゲーションまで完結できるようにする。

本仕様書はハッカソン向けMVPを対象とする。実店舗展開ではなく、単一のデモ店舗での動作を目指す。

## 問題・背景

- スーパーやコンビニで探し物が見つからないとき店員に話しかける必要があるが、コミュニケーションが苦手な人や急いでいる人にとってストレスになる
- 店員にとっても、話しかけられると現在の作業を中断する必要があり効率が落ちる

## 解決方針

店員に場所を聞く代わりに、スマホの中で商品の検索からナビゲーションまでを完結させる。

## スコープ

- 対象: デモ店舗1店舗のみ(将来的にはマルチテナント化を想定するが、本MVPでは対象外)
- 対象外: マルチテナント対応、屋内リアルタイム位置トラッキング(BLEビーコン、AR等)、決済・在庫連携などの周辺機能

## システム構成

| 要素 | 採用技術 |
|---|---|
| フロントエンド/バックエンド | Next.js(現行プロジェクト) |
| データベース | Supabase(Postgres + Auth + Storage) |
| 3Dナビゲーション | Unity WebGLビルドをNext.jsページに埋め込み |
| AI | `claude`コマンド(Claude Code CLI)をサーバーからサブプロセス呼び出し。claudeサブスクリプションのログインを利用し、Anthropic APIキーは使わない(詳細・経緯は「AI連携仕様」参照) |
| バーコード/QR読取 | ブラウザのカメラAPI + バーコード/QR読取ライブラリ(例: `@zxing/library` 等、実装時に選定) |

## 画面一覧

1. **店舗トップ画面**(入店QRコード読み取り後): 店舗説明、検索入力(Q&A形式)
2. **AI検索結果画面**: 商品/マップ/リストのタブ表示。リストの商品を選ぶとUnity WebGLナビゲーション(現在地・ルート表示)が起動
3. **管理者ログイン画面**: メールアドレス+パスワード
4. **店舗管理画面**: 商品登録/商品削除/商品一覧への導線
5. **商品一覧画面**: 登録済み商品のリスト表示、検索機能

## 機能仕様

### 消費者用

- **入店・位置取得**: 店舗入口に設置された「スタート地点QRコード」をスキャン → 店舗ページ(店舗ID・スタート地点情報付き)にアクセスし、位置情報の取得とWeb画面表示を同時に行う
- **商品検索**: AIを使い、抽象的なテキスト(例:「カレーに使う調味料」)でも商品がヒットするようにする。Claude Agent SDK経由でSupabase上の商品DBを検索するツールを呼び出し、該当商品(複数可)と棚位置を特定する
- **結果表示**: 商品/マップ/リストの切り替えタブで検索結果を表示
- **ナビゲーション**: リストから商品を選択すると、Unity WebGL内でスタート地点から該当棚までのルートアニメーションを再生する。リアルタイムの現在地追跡は行わない(スタート地点は固定、以後の移動は追跡しない)

### 管理者用

- **ログイン**: メールアドレス+パスワードで認証(Supabase Auth標準)
- **商品登録**: 棚バーコードをスキャンして棚を特定 → 商品バーコードをスキャン/入力 → 商品名・商品説明(抽象検索用)を入力 → 棚と商品を紐付けて保存
- **商品削除**: 棚バーコードをスキャン → その棚に登録済みの商品一覧を表示 → 削除したい商品を選択して削除
- **商品一覧**: 店舗内の全登録商品を一覧表示し、名前などで検索できるようにする

Supabase上に構築する。テーブル設計は確定済み。詳細・DDL・RLSポリシーは `docs/データベース設計.md` を参照。

## AI連携仕様

- **検証結果(実装初期に判明)**: 当初案の「Claude Agent SDKをclaude.aiサブスクリプションのOAuth認証で呼び出す」は、
  Anthropicの利用ポリシー上、サードパーティ製品がclaude.aiログイン/レート制限を自社製品に組み込むことを
  原則禁止しているため不可(Agent SDKが公式にサポートする認証はAPIキー、またはBedrock/Vertex/Foundry等のみ)
- 代わりに、サーバーサイド(Next.js API route)から`claude`コマンド(Claude Code CLI)を
  `child_process`でサブプロセス実行する方式を採用。この開発機/デプロイ先で`claude login`済みの
  claudeサブスクリプション認証をそのまま利用でき、Anthropic APIキーの契約は不要
  (インタラクティブログインできない環境では`claude setup-token`で発行した長期トークンを使う)
- 商品検索は、Supabaseの商品テーブルをサーバー側で先に取得し、その一覧をプロンプトに含めて
  `claude -p --output-format json --json-schema ...`で一括検索させる方式(単一デモ店舗・少数商品の
  MVPスコープでは、ツール呼び出し型エージェントより単純で確実なため)。ユーザーの自然文から
  該当商品と棚位置(`location_code`)を特定し、`structured_output`としてJSONで返す
- **残課題**: `claude`コマンドが実行環境にインストール・ログイン済みであることが前提のため、
  Vercel等の一般的なサーバーレスホスティングにはそのままデプロイできない。ハッカソンデモとしては
  開発機/手元サーバーでの起動を想定。将来的に一般公開する場合は、Anthropic APIキー契約への
  切り替えを再検討する

## 屋内位置・ナビゲーション仕様

- 店舗入口に「スタート地点QRコード」を設置。読み取ることで店舗内の基準座標を取得
- 商品選択後、Unity WebGL内でスタート地点から目的の棚までの経路をあらかじめ用意したロジック/経路データに基づきアニメーション表示(棚位置のUnity座標は `shelf_locations` テーブルで管理。詳細は `docs/データベース設計.md` を参照)
- リアルタイムの現在地追跡は行わない

## 将来拡張(本MVPのスコープ外)

- マルチテナント対応(複数店舗が同一アプリを利用する構成)
- 屋内でのリアルタイム位置トラッキング(BLEビーコン、AR等)
- 決済・在庫連携などの周辺機能
