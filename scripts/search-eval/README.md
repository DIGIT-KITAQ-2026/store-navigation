# 抽象検索の評価

「喉が渇いた」のような目的・状況の言い回しで、期待する商品にたどり着けるかを測る。
**検索まわりを変えたときは、必ずここで前後を比較してから採用すること。**

商品名そのもので検索する場合は文字列一致で確実に当たるので、ここでは測らない。
測りたいのは意味検索の質。

## 使い方

開発サーバー(`npm run dev`)を起動した状態で:

```bash
cd scripts/search-eval
node eval.mjs
```

`cases.json` の期待商品は、**現在Supabaseに登録され、かつ `category_id` が付いている40件**から
選んである(`category_id` 未設定の旧商品は検索対象外)。商品が増減したら見直すこと。

## これまでの計測

| | 到達 | 1位一致 |
|---|---|---|
| 手を入れる前(e5-small) | 18/20 | 15/20 |
| 意図語の展開(intentQueries.ts)を追加 | 20/20 | 17/20 |
| 文字の重なりで同点を崩す(rankMatches.ts)を追加 | 20/20 | 19/20 |
| 埋め込みモデルをruriに変更 | **20/20** | **20/20** |

## 埋め込みモデルは言語で使い分けている

`src/lib/aiSearch/clip/models.ts` を参照。

| 言語 | モデル | サイズ |
|---|---|---|
| 日本語 | `sirasagi62/ruri-v3-30m-ONNX` | 147MB |
| 英語・中国語・韓国語 | `Xenova/multilingual-e5-small` | 470MB |

日本語はruriが明確に強い。意味検索層だけの実測(この20問)は e5 が到達18/20・1位一致17/20、
ruriが20/20・19/20。サイズも3分の1になる。

ただし**ruriは中国語・韓国語で大きく落ちる**ため、日本語以外はe5のままにしている
(実測: 「마스크」でe5は1位・ruriは31位、「口罩」でe5は3位・ruriは37位)。

試して効かなかったもの:

| 試したこと | 結果 |
|---|---|
| `multilingual-e5-base`(1110MB) | 到達 18→19、1位一致は変わらず。サイズに見合わない |
| `gte-multilingual-base`(1256MB) | ruriと同等(20/20・19/20)だがサイズが8倍以上 |
| 商品テキストを説明文だけにする | 到達 18→19。「喉が渇いた」は直らず |
| 商品テキストの名前と説明を別々に埋め込んで最大を採る | 変化なし |
| カテゴリーを商品テキストから外す | 変化なし |

## 順位はどう決めているか

意味検索のスコアは僅差で並ぶため、それだけでは順位が実質決まらない。
そこで `src/lib/aiSearch/rankMatches.ts` で並べ替えている。

1. 商品名が検索語に当たった商品を先頭に寄せる
2. その中では、検索語と商品テキスト(名前・カテゴリー・説明文)の**2文字の並びの重なり**が多い順
3. 重なりも同じなら元の順序(意味検索のスコア順)を保つ

これで「食器を洗いたい」の1位が小皿からキッチンスポンジに直った
(小皿の説明文「取り分けや薬味用に使う小さめの平皿」は検索語と1文字も重ならない)。

重なりでも決まらない場合だけ `intentQueries.ts` に対応付けを書く。
現在の登録は「書き間違えた」→消しゴムの**1件だけ**。消しゴムの説明文「鉛筆書きをきれいに消せる」と
鉛筆セットの「筆記や下書きに使う」がどちらも「書き」を含むため、重なりでは崩せない。

**表を増やす前に、まずここで意味検索が届いていないことを確かめること。**
以前は飲み物の言い回し5件も書いていたが、ruriに替えたら不要になった。

## 「該当なし」の判定

`src/lib/aiSearch/clip/matchProducts.ts` を参照。商品への最高類似度が、
店が扱わない物体(`outOfStoreLabels.ts` の587品目)への最高類似度を、
モデルごとの基準値以上に上回らなければ0件にする。

**基準値はモデルごとに測り直すこと。** スコアの出方が違うため、使い回すと壊れる
(ruriに替えた直後、e5用の基準のままで20問中6問が0件になった)。

店外ラベルが英語なので、日本語以外の検索語はラベル側にも強く似る。
そのため多言語モデル側の基準は日本語より緩くしている(-0.05 / -0.04)。
